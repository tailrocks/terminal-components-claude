# Showcase coverage allowlist (plan §7, SC0). One line per capability id of
# `junie_tui::catalog` that the showcase does not show yet:
#   id | reason | SCn        pending; SCn is the step that shows it
#   id | reason | permanent  intentionally never shown (a genuine exclusion
#                            with its own reason: runtime plumbing, a
#                            deprecated alias, an app-only brand piece)
# A function the demo of its owning type runs (render, input, hit ids,
# operations, plumbing) is not listed here: it is declared in `VIA`
# (src/bin/showcase/coverage.rs) once its owner is shown, and until then is
# pending on the step that shows the owner.
# Each SC step deletes its own lines. A line for an id that is now declared in
# src/bin/showcase/coverage.rs, or that the catalog no longer has, fails the
# gate (src/bin/showcase/app_tests_catalog.rs) as stale.
#
# `app::<bin>::<name>` lines name an app-local pattern that is deliberately
# never extracted to the library nor shown; they must be `permanent` and
# their app (`src/bin/<bin>`) must exist.
