# Project goal

Build a reusable Rust terminal component system and migrate the four deterministic demonstration applications onto it while preserving the exact product behavior and visual language defined by the design/interaction-polish reference.

The current design checkout is the product-reference implementation. The main workspace is the structural direction and contains partial migration work; neither a successful build nor a green self-baseline establishes parity or completion. See [docs/README.md](docs/README.md) for the maintained documentation map, [docs/design.md](docs/design.md) for product authority, [docs/architecture.md](docs/architecture.md) for current and target structure, and [docs/plan.md](docs/plan.md) for retained requirements and acceptance gates.

Detailed future requirements remain in the shared component plan, remaining-work ledger, improvement specifications, and sealed task packages. Their status must be determined from current implementation and verification evidence, not from historical progress reports.
