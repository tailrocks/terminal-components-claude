## Behavioral contract

1. Checked marker and focus gutter occupy different cells. Focus must not change the checked value.
2. Enter/Space or a completed click requests the inverse value. If the caller declines that action, the next draw still displays the caller-supplied value.
3. Only the clipped control/label area is a hit target; short rows must not capture adjacent controls.
