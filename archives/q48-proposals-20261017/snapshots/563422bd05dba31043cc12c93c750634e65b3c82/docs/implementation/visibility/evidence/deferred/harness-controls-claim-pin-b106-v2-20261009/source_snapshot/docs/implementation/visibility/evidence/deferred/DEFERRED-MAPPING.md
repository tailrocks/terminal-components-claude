Holla’s Activity tab imports a separate app-local `ChipBar` from `crate::tui::widgets` ([`activity.rs`](../../../../../crates/holla-ui/src/screens/activity.rs#L25)); that control is not the W06 `termrock-navigation` component.

## Common-driver boundary

The current [`termrock-e2e` Step enum](../../../../../crates/termrock-e2e/src/lib.rs#L58) provides `Press` and `Checkpoint`. Its structured checkpoint assertions are text-oriented (`contains`, `absent`, and `same_line`, see [`lib.rs`](../../../../../crates/termrock-e2e/src/lib.rs#L1491)). The registered Holla pilot therefore does not supply mouse, wheel, paste, caller data resupply, virtual-time sampling, caret, or cell-style assertions for these rows. Direct Harness tests remain separate evidence; they must not be promoted to common public coverage.
