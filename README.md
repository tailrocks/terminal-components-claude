# Termrock

A Rust terminal UI component library with deterministic demonstration applications. The modular refactor is incomplete and not ready for product use.

Start at the [documentation index](docs/README.md). `main` defines the intended split architecture. `design/interaction-polish` defines the product experience, including UI, colors, interactions, and its planned work. The implementation must satisfy both.
