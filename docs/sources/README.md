# Source records

This directory preserves source documents used to reconstruct architectural decisions and task requirements. Their original wording, dates, pins, status claims, and execution instructions describe the campaign or branch where they were recorded; they are not current project instructions or a report of current readiness.

| Record | Role |
|---|---|
| [PLANNING_GOAL.md](PLANNING_GOAL.md) | Historical planning source whose requirements are cross-referenced by the task and traceability inputs. |
| [REFACTORING_COMPLETION_PLAN.md](REFACTORING_COMPLETION_PLAN.md) | Recorded planning and proof-contract source used by the refactoring task catalog. |
| [`main/`](main/) | Historical main-branch architecture, goals, state, and handoff source material used by decision and obligation ledgers. |

Preserve these source records wherever structured task inputs bind to their content. Do not use their old branch tips, progress statements, model assignments, or authority hierarchy as current state. For current project authority, use the [design contract](../design.md), [architecture](../architecture.md), [active plan](../plan.md), and current source and verification evidence.
