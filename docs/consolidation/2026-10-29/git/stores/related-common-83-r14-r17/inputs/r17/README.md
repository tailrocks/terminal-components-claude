# Git admin byte snapshots and lineage supplement r17

This addendum contains deduplicated raw bytes for current per-store refs, reflogs, indexes, HEAD/admin pointer files, shallow/graft/alternate metadata, and any custom hook files (none were found). Every payload is keyed by SHA-256 and has source-path mappings and pre/post stat identity. Raw reflog messages are inert data and require static privacy review before publication. Raw Git config values were not copied; normalized field names and exclusions are recorded separately.

No Git or source files were modified. These snapshots supplement object payload mapping in r14 and OID lineage/closure relations in r15. They do not replace remote archive or readback verification.
