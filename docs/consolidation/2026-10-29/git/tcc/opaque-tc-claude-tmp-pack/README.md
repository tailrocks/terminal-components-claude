# tc-claude temporary pack: opaque byte custody only

This archive preserves the exact 279,109,631-byte file `tmp_pack_1quA7Q` from the tc-claude TCC repository object-pack directory. The bytes are split into six ordered SHA-256-addressed chunks no larger than 48 MiB. `manifest.json` binds source path, mode/owner, full-file hash, each chunk hash, and ordered reconstruction. The independent sanitized-origin and raw-content publication review is copied as `opaque-pack-publication-review.json`.

The source is not a valid indexed pack: its stored trailing SHA-1 does not match the digest over preceding bytes. It has no index sidecar. The header-declared object count is retained as source metadata only; this archive makes no object-identity, object-count verification, or usability claim. Do not feed it to `index-pack`, repair it, or treat it as a repository object store.
