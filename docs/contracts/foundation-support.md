## Routing order open contract

At c817, `KeyRouter::once` lets an unconsumed layer response end ordinary routing. An enabled modified quit chord can still request quit before the return. Normal routing runs shell `keys` bindings before chrome and page input. During capture, the page receives a chance before `keys`. This differs from the source comment promising that `keys` runs after the page declines.

Keep T19-KEYS-TIER-01 open. T19 owns the routing-order policy. T01 records the code and source-comment conflict. T38 plans public-path cases. Cases cover capture on or off, chords present in both tiers, consumed or ignored layer/menu responses, selection and copy, and exact modified quit chords. T37 makes no behavior change; behavior remains `NOT VERIFIED`.

### Footer priority conflict

At product input, `Footer::compose` applies the dirty pin first, then normalizes all retained hint priorities when the status tone is `Role::Danger`. It does not remove or reorder hints. This source assignment conflicts with the comment promise that `HINT_PINNED` survives an error. T19-FOOTER-PIN-01 stays open under T19. T19 must resolve pin/error precedence before any behavior change. T01 must record the conflict. T38 must review the public-path cases. T12 owns downstream `HintBar` rendering checks.

The reviewed case plan must cover:

- Pinned, normal, auto, and custom priorities.
- Dirty state with a matching, nonmatching, or absent pin key.
- Danger, non-danger, and absent status.
- Error entry and clear while dirty.
- Top-layer and fallback hints, Tab-next, and delivery filtering.
- Retained hint order and labels.
- Downstream visible priority at narrow width.

## Modal backdrop and color downgrade

The source-backed modal mapping preserves the symbol. It replaces modifiers, then applies `DIM` only to nonblank covered cells. Baseline modal dim keeps glyphs, makes accent and secondary ink faint, and keeps ghost gray when a color already fails contrast. At ANSI16 and Mono, covered cells use muted dim ink because those planes do not carry the per-source ghost ladder. The concrete-color mapping returns the mapped foreground and background and whether the source cell was blank.

The frozen outputs differ. Showcase dialog underlays have no `DIM` runs. TablePro picker underlays have `DIM` at ANSI16 and color `none`. The shared mapping retains TablePro's pinned `DIM` behavior. Keep the policy open as T11-MODAL-DIM-01. T11 owns the shared mapping; T22 reviews Showcase and T29 reviews TablePro. T01 records the conflict, and T38 plans public modal, disabled, and nested-layer cases. Do not claim equal outputs or new visual acceptance.
