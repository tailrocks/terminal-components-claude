# Original checkout incident and recovery

A subagent assigned a one-file Clippy investigation mistakenly ran a branch switch in the original checkout at `/Users/donbeave/Projects/terminal-components-claude`, instead of creating and using an isolated worktree. Its command attempted to switch from the reference design branch to a WIP based on PR #38. The switch ran for about a minute and was interrupted. Git retained the design branch and index while files were partly removed or replaced by the PR #38 tree. The subagent initially reported the original checkout untouched; its later command audit corrected that assurance. The coordinator accepted the earlier assurance without checking it and is responsible for that mistake.

Independent inspection found 1,122 absent tracked paths and 14 modified tracked files. Every index entry still matched design HEAD `f2f6eb716c4a512be3dc9423742fa06e86879b32`; all 14 modified files exactly matched accidental target `2ce39f5cc33a9af53d2794ee429279fc17e75d1e`. The user requested restoration and explicitly declined backups. After exact preimage checks, a scoped Git restore recovered only those 1,136 paths from the unchanged design HEAD. No reset, branch move, broad clean, source backup, or design commit/push was performed.

The user then explicitly requested removal of six extraneous directories: `.github-gen/`, `.github/actions/u26/`, `.github/actions/velnor-tools-prelude-u26/`, `baseline/`, `baselines/regen-sidecars/`, and `baselines/tuiscotti-v1/`. An independent content audit checked all 67,315 actual files. None was tracked by design HEAD; 67,314 exactly matched the accidental PR #38 tree. One HTML file was a zero-byte interrupted write at the incident boundary. A separate reviewed exception permitted removal of only that empty placeholder while its exact inode, timestamps, mode and empty content remained unchanged. Every file was checked immediately before deletion; unknown or changed content would stop cleanup. Only enumerated files and subsequently empty directories were removed.

Independent final verification confirms all six roots absent, a completely clean original working tree including untracked status, unchanged design HEAD and all 13,795 index path/blob/mode/stage entries. A later raw index hash changed without a staged-entry difference; the review records the timing and does not attribute ordinary cache refresh to source loss. No backup was created. The frozen tag, release, main branch and design history were not changed.

All future mutating commands must specify the isolated worktree explicitly and assert its absolute directory and branch before mutation. Worktree creation must not include a branch switch in the original checkout. A worker's assurance is insufficient when an interrupted Git operation occurred: inspect branch, index and filesystem evidence before reporting safety. The original checkout remains outside product work.
