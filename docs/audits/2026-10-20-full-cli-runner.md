# Full frozen CLI runner

`tools/frozen_baseline.py live-compare` extends the approved single-case static-snapshot check into a live paired runner. The immutable oracle remains the signed `visual-baseline` source commit `4169783ae883788186d161af09ba9c481bd84e5c`, tag object `2718a6b8127a522a3d351d0b4bdb7542fc8da542`, and Tuiscotti revision `a1ea27f757d75d07b05499276cd932e9f8e067ad`.

The runner builds no product changes into the frozen applications. It creates a separately verified live test source from the same archive, applies only the deterministic test-harness patch in `tools/frozen_cli_pair.patch`, and copies the exact versioned helper source into that test target. Application sources, manifests, lockfile, and original snapshot tree must retain their frozen hashes.

Each selected ignored scenario runs against real CLI binaries in three phases: capture frames from the isolated frozen binary into a new runtime expectation root, replay the frozen binary against those frames, and compare the candidate against the same root. Each scenario must emit one or more checkpoint receipts. The runner checks receipt identity, frame digest, order, per-scenario coverage, expected-store inventory, and candidate-phase expected-store immutability. Runtime expected frames are never written into the frozen snapshots.

The frozen application contributes exactly 28,895 ignored scenarios and 20 ordinary checks; the separate Table extension adds 174 ignored scenarios. `live-compare --all` selects all 29,069 scenario cases after independently checking both inventories. It runs scenario cases in fixed-order chunks no larger than 512 and caps every Nextest invocation at 230 seconds. Eleven source-only checks run once without a binary override; nine CLI checks run once against each binary directory, with pairing flags absent. Reports expose `registered_cli_complete` for this bounded test scope. They always keep `acceptance_complete` and `overall_acceptance_complete` false because registered CLI checks do not by themselves certify full architecture or every application flow.
