## Method

1. Inventoried PR #26 reusable behavior modules: `src/ui` (popup, modal, layer, layers, reveal,
   tooltip, measure, columns, layout, scroll_view, list_core, context, pane_tree, edit_menu), `src/core`
   (scroll, hit, pointer, selection, list, text, edit, focus, typeahead), `src/widgets` (table, grid,
   file_browser, text_select, dialog, menu, select, picker), `src/theme.rs`.
2. For each behavior, searched the current termrock crates for the same contract (public type or
   builder), not the same name.
3. Recorded present / app-only / absent, with file:line on both sides.
4. Cross-checked the branch's own records (`docs/architecture/termrock-migration-matrix.md`,
   `docs/handoff/README.md`, `docs/audits/2026-10-20-false-parity-inventory.md`) so a claimed gap is
   not already explained as a deliberate deviation.
