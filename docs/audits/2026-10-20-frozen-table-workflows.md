# Frozen CLI table workflows

The paired CLI harness adds 174 ignored `libtest-mimic` trials for six Showcase table workflows. The test source runs the isolated `showcase --page tables --motion paused` binary through the frozen Tuiscotti PTY harness and routes every recorded state through the paired frame gate. The frozen application source, Cargo manifests, lockfile, and approved visual snapshots remain untouched.

The workflows cover Owner ascending/descending/clear, Changes ascending/descending/clear, keyboard sorting cycle, horizontal scroll then Changes sort, Owner sort then hover by stable row ID `#1042`, and Owner sort then activation with the `Selected Fix flaky checkout integration test` result. Tests capture named checkpoints in order and assert sort direction, clear state, stable target, and activation result.

The matrix includes 72x20, 80x24, 100x30, 120x40, and 160x50 at truecolor, 256 color, 16 color, color disabled, and `NO_COLOR`; 40x12 and 60x18 run at truecolor and `NO_COLOR`. Cases below 120 columns capture their requested initial terminal, then resize to 120x40 before interaction because the frozen table header is not actionable at smaller widths. Narrow cases boot at the frozen 72x20 minimum, resize to the requested narrow viewport and capture its minimum-size screen, then reveal 120x40. Each resize checkpoint is mandatory in every applicable phase.

`tools/frozen_cli_extensions.json` is the exact case inventory and ordered checkpoint manifest. IDs use `termrock_extensions::showcase::table_sort::{journey}::{cols}x{rows}::{color_mode}` and remain disjoint from the frozen baseline's 28,895 ignored scenarios and 20 ordinary checks. Runtime expected frames are created only in the separate paired-run artifact root; these tests never bless or modify the original snapshot corpus.
