# Nextest Rust documentation inventory guard

This increment adds a required `termrock-xtask` integration test. Generated CI already runs that package through `cargo nextest` in default and testing configurations. The test inventories tracked Rust and Markdown files, validates Cargo metadata package targets and README inputs, and rejects executable Rust documentation until its example has a compiled public-consumer test. It does not alter doctest tasks or package manifests.

The reviewed source inventory at commit `7483ce5208e054291e9aebdfc12cf15a42bbb41d` contains 39 generated doctest package targets and 78 default/testing doctest tasks. Independent review found no runnable, `no_run`, `compile_fail`, or `should_panic` Rustdoc blocks. It found one explicitly ignored pseudo-code block at `crates/termrock-runtime/src/ui/paint.rs:205-208`; the guard recognizes only that exact path and normalized body. Any changed or additional ignored block fails.

The guard reads only tracked `.rs`, `.md`, and `.markdown` files instead of the repository's large binary and archived evidence corpus. `cargo metadata --locked --offline --no-deps` supplies the complete workspace target and package README inventory. Missing manifests, targets, tracked source paths, or unreadable documentation fail closed. Rust doc attributes, conditional doc attributes, included doc inputs, and macro-produced doc attributes currently fail closed pending explicit inventory review. Markdown parsing recognizes Rust and edition fences, doctest mode labels, unlabeled Rust syntax, Rustdoc block comments, and indented Rust examples. Shell fences, plain prose, and Rust-looking text inside ordinary/raw source strings are covered by negative fixtures.

The guard's real workspace scan reports 94,924 tracked paths, 627 Rust files, 72 Markdown files, 47 workspace packages, 222 Cargo targets, no package README, and the one expected ignored example. Focused nextest runs all five guard cases with zero skips. Strict xtask Clippy and formatting checks pass. A broader xtask nextest run passes 36/37 tests; the existing ownership test reports 157 findings across application sources and three runtime files. This guard does not modify ownership rules or exceptions, and this increment does not attribute those findings to a baseline without a separate baseline run.

Current checks cover the real workspace and synthetic additions for Rust, edition, `no_run`, `compile_fail`, `should_panic`, unlabeled, indented, block-comment, direct and conditional doc-attribute/include, and macro-attribute inputs. Negative fixtures also cover non-Rust fences, prose, and source strings. This guard is not a doctest policy approval. Do not remove generated doctest tasks or set `doctest = false` until an independent reviewer checks the guard on the exact committed tree and Velnor 0.1.30 regeneration proves that only the reviewed empty tasks disappear.
