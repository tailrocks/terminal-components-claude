# Stage one owned-process lifecycle

Status: implementation and fixes for reviews `80cd90f3a78ee9dc51b8ef543a98043321751d42` and `d6b2edb66bc11f60c3a9e8ecfae1dd8bf3af1d9b` are committed on `wip/canonical-stage1-owned-20261021`; independent review of exact source `a46842108149a1421030e4a040c890fadecc671e` clears this bounded stage-one implementation. This record does not authorize running the real `prepare` command, reading the frozen key, preparing a new baseline, or capturing frames.

The opt-in `prepare --owned-lifecycle` path adds one monotonic work budget, a fixed cleanup reserve, cancellation-safe signal recording, and an anchored broker for the stage-one fixed `git rev-parse` and `git archive` commands. The legacy default path and other runner stages keep their existing behavior. The owned path bounds work to 200 seconds and reserves 15 seconds for cleanup, below the 220-second supervisor ceiling. Extraction and digest loops check the same work deadline.

The broker remains the unreaped process-group leader until the parent verifies that no live members remain except the anchor, then accepts a one-byte release. The broker catches termination signals while its executed Git child receives default signal dispositions. Parent-pipe EOF triggers broker-owned termination of the group. If the membership observer fails, the still-live broker validates that it remains its own process-group leader, sends TERM to that anchored group, then sends KILL after a bounded grace; this deliberately terminates the broker and cannot be treated as successful cleanup. Group membership uses an absolute `/bin/ps` path, never an unchecked `PATH` lookup, and malformed rows fail closed. Group signaling remains limited to a live anchor; no post-release or post-reap group signal is allowed. Parent-side `SIGKILL` cleanup remains an unverified failure and cannot produce a successful prepare result. Failure logs remain in the reported temporary directory.

The group contract covers the fixed, noninteractive Git commands and same-session children. It does not claim containment of a child that creates a new session, a process stuck in an uninterruptible kernel operation, or arbitrary future tool wrappers. Those cases require separate ownership edges and review.

Focused tests use synthetic Python commands and local synthetic archives only. In addition to the original cases, regression tests cover EOF plus observer failure, malformed observer output, observer timeout, absolute process-list invocation, and both no-context and checked extraction preserving tarfile's delayed directory metadata for restrictive archived directories. No real frozen source preparation, key access, capture, replay, candidate comparison, or reference update is part of this increment.
