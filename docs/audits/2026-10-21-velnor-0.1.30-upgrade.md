# Velnor Actions 0.1.30 upgrade

Scope: PR #38 source branch only. `design/interaction-polish`, `main`, the frozen baseline tag, and other branches were not changed.

## Release and configuration

Velnor Actions 0.1.30 is the latest published release inspected for this change. GitHub lists publication at 2026-10-20 19:25:36 UTC and release source commit `a6b1d7873151dc62711844158490e8687d191943`. The official release manifest was downloaded from the release and verified against its published asset digest: SHA-256 `81f24072a16f35f30845fd373b114f7c615e9119ee434fe39dab83de84fc56ea`. It records the macOS ARM64 binary digest as `7cb74f0a82edbc9545d5d2170387a21dab33c84e8674610fd1e46dad2ca2ad3c`; the installed binary matched that digest and reported `velnor-actions 0.1.30`.

The 0.1.30 schema rejects the prior disabled `binary_release` fields `enabled`, `package`, and `bin`. The old nested `preview.producer` and `preview.evidence` tables also do not match the current schema. Both channels were disabled in the old configuration. Running `velnor-actions config migrate --to 2 --write` canonicalized that configuration to the current schema's disabled preview and stable defaults, with no release products enabled. No release workflow was enabled.

`mise.toml` and `mise.lock` now pin 0.1.30. `mise lock github:tailrocks/velnor-new@0.1.30` resolved the published release and verified platform artifacts. The checked-in release manifest is byte-identical to the official 0.1.30 release asset.

## Remaining CI blockers

- The generated plan includes Rust doctest commands that invoke `cargo test --doc`, which conflicts with this repository's rule to use Cargo Nextest and never `cargo test`. No task was skipped or waived by this migration.
- The generated plan job still has a five-minute timeout. A prior checkout attempt exceeded that budget; the unreleased upstream proposal to configure a longer timeout was not adopted.
- Velnor emitted `tool_install_unverified` for Rust 1.99.1 because the current tool lock has no Rust checksums. Generator output was still produced; this warning needs a separate tool-provenance resolution.
- Full GitHub Actions execution was not part of this migration. The direct actionlint run cannot validate Velnor-specific workflow extensions; job completion and application parity remain unverified here.

These gaps remain acceptance blockers. Do not treat generated files or a successful plan as passing CI or completing Termrock parity.
