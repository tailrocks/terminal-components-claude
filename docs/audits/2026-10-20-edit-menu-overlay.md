# Shared edit-menu overlay increment (2026-10-20; integration pending)

`termrock-overlays` exposes `EditMenu`, `EditMenuState`, and `EditMenuAction` as an adapter around existing `ContextMenu`/layer machinery. `EditMenu::new(owner)` derives the stable `owner.sub("edit-menu")` ID. The caller passes the real `EditMenuRequest` anchor and current `EditCapabilities`; the adapter renders only baseline-available rows (read-only fields show Copy and Select all, while editable fields also show Cut and Paste), disables unavailable operations (including empty clipboard paste), and yields a typed `TextEditCommand`. Select all advertises Ctrl+A through the same effective-chord/key-remapping path as other context-menu commands. `EditCapabilities::editable` is independent of sensitivity so editable secret values retain baseline menu rows while protected copy/cut remain disabled. Escape and outside dismissal yield a typed close reason. Editor buffer, selection, caret geometry, and execution remain in the field component.

Consumers process the field update before the menu update and currently need to preserve the field draft while focus is nested in the popup. A runtime/layout focus-retention contract is being designed; the existing tests' conditional `BlurPolicy::Keep` is transitional and does not satisfy the component ownership requirement. Command timing also needs a runtime close/focus-restoration signal: the current adapter yields the typed command on the menu activation event, before the next runtime tick applies queued layer closure. These two findings remain open and must be resolved before integration.

Runtime tests cover a TextInput opening its menu by Shift+F10 and choosing Select all exactly once; a separate TextArea consumer right-clicking and pasting at the prepared caret; Escape and outside dismissal; blocked typing into the background field; restored focus and cursor; baseline read-only rows; secret, disabled, and clipboard availability; and the Ctrl+A effective chord. Full picker wiring and frozen-baseline CLI parity remain open.
