# Approved reference samples

This directory is empty until an independent reviewer approves a stable PR26 A/B capture. The runner never writes here. Store the approved sample for each logical checkpoint under `first/<app>/<checkpoint>/pixels-<platform-key>.tui.json`, for example `first/showcase/initial/pixels-macos-aarch64.tui.json`. Platform suffixes are sample metadata; the fixed checkpoint denominator remains twelve. Keep the original candidate and SHA-256 in the review record. Do not copy a PR38 candidate into this directory.
